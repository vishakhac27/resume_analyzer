# AI Resume Analyzer & Career Advisor

An AI-powered Resume Analyzer and Career Advisor that helps users evaluate their resumes, identify missing skills, and receive personalized career recommendations. The application uses AI to provide resume feedback, ATS optimization tips, and guidance on suitable career paths.

## 🚀 Features

- Upload Resume (PDF)
- Resume Content Extraction
- ATS Resume Analysis
- Skill Identification
- Missing Skills Detection
- Resume Improvement Suggestions
- AI-Powered Career Recommendations
- Personalized Learning Suggestions
- Responsive User Interface

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask)
- **AI:** GROQ API
- **Database:** SQLite

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/vishakhac27/resume_analyzer.git
```

### 2. Navigate to the project

```bash
cd ai_resume_analyzer
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Add your Gemini API Key

Create a `.env` file and add:

```env
GROQ API Key=your_api_key
```

### 5. Run the application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
